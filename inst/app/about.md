## What is shinySCP?

`shinySCP` is a demo Shiny app for browsing files on a remote server over SSH. It takes inspiration from graphical file-transfer clients such as WinSCP and FileZilla.

## Why shinySCP?

I created shinySCP to learn more about Shiny and explore how a familiar remote file browser could work as a web app.

## What's next for shinySCP?

The public app provides a fictional, read-only demo filesystem. You can navigate directories, refresh directory listings, filter entries, and select a file or directory. Real SSH login is available only when explicitly enabled for a trusted private deployment.

Planned features include:

1. Downloading a selected file.
2. Previewing supported text files.
3. Adding carefully scoped file operations.
